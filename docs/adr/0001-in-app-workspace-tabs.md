# 多工作區用 App 自己畫的分頁，不用 macOS 原生視窗分頁

同時開多個工作區時，主視窗只有一個，頂端由 App 自己畫一排工作區分頁，每個分頁各有一個 `WorkbenchModel`。原生視窗分頁（每個工作區一個 OS 視窗，共用 `tabbing_identifier`）看起來比較省事，但我們沒有採用：GPUI 只在系統設定「偏好標籤頁」為「永遠」或全螢幕時，才把視窗併成分頁，macOS 預設會開成好幾個獨立視窗；Linux 和 Windows 則根本沒有原生分頁。自己畫的分頁在三個平台上的行為一樣，也不受使用者的系統設定影響。

## Consequences

- 結束 App 前要等每個分頁都收尾完成；任何一個分頁正在貼上，就拒絕結束。
- 分頁共用同一個行程，所以 git 額度（`gitrun`）和記憶體是共用的。收尾時只等自己分頁的 git 工作。
- 兩個分頁可能指向同一個 repo，所以檔案貼上和 commit 重放改用跨行程的檔案鎖，鎖放在 git dir 裡。
